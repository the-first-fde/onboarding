description: 팀 판단 또는 작업을 공통 Issue 초안으로 정리할 때 사용한다.
---

[루트 시작 안내](../../../README.md), [루트 지침](../../../CLAUDE.md)과 [CONTRIBUTING](../../../CONTRIBUTING.md)을 따른다.

기존 Issue를 읽기 전용 조회해 중복과 연결을 확인한다. 조회 불가면 NOT RUN으로 표시한다. .github/ISSUE_TEMPLATE/에서 feature/bug/refactor/research/task를 선택한다. 범위/근거/상태/인수 조건/민감정보 없는 재현/담당 미배정을 기록한다. 초안을 제시하고 실제 등록 직전 명시 승인을 요청한다. 승인 전 gh issue create/API 쓰기 금지. 안전한 독립 작업은 계속한다.

문서와 구현이 다르면 해당 README·CLAUDE.md, 코드, 관련 Issue·Spec·계약을 대조하고, 확인한 근거·영향·팀이 결정할 질문을 초안에 포함한다.
