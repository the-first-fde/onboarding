description: 팀의 제출 목표와 범위를 milestone 초안으로 정리할 때 사용한다.
---

[루트 지침](../../../CLAUDE.md)과 [CONTRIBUTING](../../../CONTRIBUTING.md)을 따른다.

.github/templates/milestone.md를 사용해 범위/미포함/담당/종료조건/기한 KST와 UTC를 기록한다. 2026-12-03 23:59 KST = 2026-12-03 14:59 UTC. 기존 milestone을 조회해 중복 확인 후 초안만 작성한다. 실제 생성·수정은 명시 승인 필요.
