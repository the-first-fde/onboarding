[루트 시작 안내](../../../README.md), [루트 지침](../../../CLAUDE.md)과 [CONTRIBUTING](../../../CONTRIBUTING.md)을 따른다.

기존 상태와 작업 브랜치를 확인한다. DoR를 만족한 승인 범위만 변경한다. tdd-workflow와 python-patterns/python-testing을 필요한 만큼 참조한다. root의 No Silent Issues 절차로 범위 밖 문제를 즉시 보고한다. 작은 변경 후 verify 실행, 실제 증거 기록. 자동 commit/push/merge/실제 MCP 금지.

구현 전에 작업 경로의 README·CLAUDE.md와 Issue·Spec·잠정 데이터 계약을 확인한다. 바뀐 개발 안내는 같은 변경에서 최신화하고 관련 링크·명령·예제를 검증한다. 불일치는 사용자에게 보고한다.
