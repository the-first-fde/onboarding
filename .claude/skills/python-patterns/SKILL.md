[루트 지침](../../../CLAUDE.md)과 [공통 Handbook](../../../docs/guides/README.md)을 준수한다.

영어 식별자와 타입 힌트, 한국어 Google Style Docstring. 구체적 예외를 처리하고 실패를 숨기지 않는다. 가변 기본 인수와 import 부작용을 피한다. subprocess는 인수 목록으로 호출한다. 명시적 설정과 작은 함수, 주입 가능한 외부 경계를 우선한다.
