# Runtime Agent Template — DEFERRED

이 파일은 실행 가능한 업무 에이전트가 아닌 작성 양식이다.

- 소유자: 미배정
- 상태: NEEDS_CLARIFICATION
- 목적/입력/출력: 담당자별 계약 문서 연결 후 작성
- 확인된 근거: 고객사 샘플 미수령
- 잠정 가정: 없음
- 허용 도구: 없음
- MCP: 미연결, 쓰기 금지
- 승인: 외부 실행은 명시 승인 필요; 실제 메일/입사 확정은 사람 수동
- 오류/재시도/멱등성/보존 기간: 계약 확정 후 정의

개발용 `.claude/agents/`와 별개다. 개발 Skills/Shell/GitHub 권한을 상속하지 않는다.
