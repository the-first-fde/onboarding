## 업무 규칙 후보와 질문

- 기준일: D-n은 입사일 기준, 주말이면 앞 평일. 「확정+2일」은 합격 확정일 기준(양식 3절). 확정일은 입사자 DB에 없어 입력이 더 필요하다(Q20).
- 조건 항목: `[경력]`은 경력 구분, `[노트북 지급]`은 노트북 지급 여부로 판단. 아니면 「해당 없음」.
- 승인·수동 전환: 모든 출력은 승인 전 외부 호출 차단, 발송·등록은 사람 수동. 승인 뒤 내용이 바뀌면 다시 승인.
- 외부 시스템: Gmail·Notion·Calendar 모두 mock/더미. 실제 MCP 쓰기 금지.
- 마스킹·로그: 금지 값은 입력 단계에서 받지 않는다. 로그에는 체크리스트 ID와 상태만 남긴다.
- 충돌/공통화: 입사자 DB 필드와 체크리스트 항목은 계획·진행 담당과 공통이다(Q14). 승인 요청 형식은 검토·승인 담당과 맞춘다.
- 샘플 요청: 누락 참조 파일(Q17).
