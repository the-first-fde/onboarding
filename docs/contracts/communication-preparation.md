# 담당자별 잠정 데이터 요구: 입사 안내 메일·리더/담당자별 준비 체크리스트 및 요청

- 담당: 종은 (이전 대화 기록, 현재 분담 재확인 필요)
- 상태: NEEDS_CLARIFICATION / 업무 구현 BLOCKED
- 기준 양식: [template.md](template.md)
- 샘플: 미수령. 실제 고객사 데이터를 저장소에 넣지 않는다.
- 확인된 사실: 초기화 범위에 업무 Schema/State/규칙 확정은 없다.
- 잠정 입력/출력/필드·타입·필수 여부: 미정, 임의 확정하지 않는다.
- 요청할 정보의 종류(질문): 승인된 안내문 양식, 리더/준비 담당 역할, 요청/완료 확인 기준, 실제 메일 수동 발송 경계
- 업무 규칙·오류·중복·시간대·권한·보존/삭제·타 담당자 의존성: 근거 수령 후 작성
- 가정: 없음. 새 탐색 가정은 PROVISIONAL로 작성한다.
- 검증: NOT RUN — 공통 업무 fixtures 생성 보류
- 확정 조건: 비식별 샘플/근거 확인 → 담당 검증 → 3인 조정 → 사람 승인/계약 버전 기록
