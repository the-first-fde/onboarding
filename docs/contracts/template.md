# 담당자별 잠정 데이터 요구사항

- 담당자/업무: 미배정
- 상태: PROVISIONAL / NEEDS_CLARIFICATION / BLOCKED / CONFIRMED / DEFERRED
- 관련 Issue/Spec/ADR:
- 확인된 근거(출처·날짜·확인자):
- 샘플 수령 여부: 미수령
- 확인된 사실:
- 잠정 가정(확정 정책으로 사용 금지):

## 입력과 출력 요구

| 구분 | 잠정 이름 | 의미/타입 후보 | 필수 여부/누락 처리 | 출처 | 민감도 | 상태 |
|---|---|---|---|---|---|---|

## 업무 규칙 후보와 질문

- 규칙 후보/근거/확인자/미확정 시 영향:
- 오류·재시도·중복·시간대·승인·수동 전환:
- 외부 시스템과 최소 권한(현재 MCP 쓰기 금지):
- 보존/삭제/마스킹/로그 정책:
- 다른 담당자와 충돌/공통화가 필요한 사항:
- 샘플 요청(가상·비식별만, 실제 자료는 Git 금지):

## 계약 확정 절차

샘플/근거 수령 → 담당자 검증 → 3인 충돌 조정 → 공통 계약·버전·호환성 합의 → 사람 승인.
그 전에는 확정 Schema/State/공통 업무 테스트 데이터로 사용하지 않는다.
