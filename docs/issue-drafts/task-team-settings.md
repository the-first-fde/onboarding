# [task] 최초 commit 예외 및 GitHub 리뷰 운영 확인

## 문제/목적
빈 main에 아직 commit이 없다. 서버 보호/플랜/담당/보안 연락·제출 버전 정책에 사람의 결정이 필요하다.

## 기존 Issue 중복 확인
2026-11-25 연결된 GitHub 조회 `repo:the-first-fde/onboarding is:issue` 결과 0건.
계정 조회 범위에 한계가 있을 수 있으므로 등록 직전에 재확인한다. 실제 등록은 하지 않았다.

## 확인된 사실/가정/범위
초기화 사용자 명세의 미확인 사항이다. 이미 해결됐다고 가정하지 않는다.
실제 업무 구현/실제 데이터 반입/외부 전송/자동 설정 변경은 제외한다.

## 인수 조건/검증
팀 리더가 초기 파일과 검증 증거를 리뷰하고 최초 commit 예외를 승인한다. 일반 1명/고위험 2명·squash·재승인·revert와 Free Private 한계를 확인하고 수동 설정한다.
