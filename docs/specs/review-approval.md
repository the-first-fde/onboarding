# 담당 업무 Spec: 산출물 검토·HITL·승인 상태 관리

- 담당: 정현님 (이전 대화 기록, 현재 분담 재확인 필요)
- 상태: BLOCKED — 샘플/업무 규칙 미수령, 초기 명세 초안만 준비
- 관련 잠정 데이터 요구: [계약 초안](../contracts/review-approval.md)
- 확인된 사실: 사용자 요청에 따라 초기화만 수행하며 업무 구현은 보류한다.
- 업무 목표: 산출물 검토·수정 요청 처리·HITL·승인 상태 관리
- 잠정 가정: 없음. 담당자가 탐색 시 PROVISIONAL로 별도 기록한다.
- 확인할 질문: 검토 기준과 산출물 종류, 사람 승인 권한/거절/만료/재승인, 상태 전이 근거
- 제외: 실제 외부 실행/실제 고객사 데이터/확정 공통 Schema·State·업무 규칙·공통 fixtures
- 인수 조건/입출력/오류/승인/테스트: 샘플과 근거 수령 후 담당자 작성 및 팀 검토
- 현재 검증: NOT RUN (업무 계약 미확정)
- 다음 단계: 계약 양식에 자료 요구와 근거를 작성 → 샘플 요청 → 분담/충돌 조정 → 승인된 작은 구현
