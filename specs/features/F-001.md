# F-001 · 채용 관측과 출처 정규화
## 목적
ATS/Notion/포털의 관측을 구분하고 합격·입사확정을 분리한다.
## 완료 조건 (EARS)
- F-001-AC1: WHEN 최종합격 통보가 수집된다 THE SYSTEM SHALL 채용 사건으로만 기록하고 온보딩을 생성하지 않는다.
- F-001-AC2: WHEN 포털 A 지원자가 ATS에 없다 THE SYSTEM SHALL Notion 원천을 사용하고 ATS 누락을 오류로 단정하지 않는다.
