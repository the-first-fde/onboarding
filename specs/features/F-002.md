# F-002 · HR 입사확정 핸드오프
## 목적
allowlist 이벤트를 HR 승인 후 온보딩에 전달한다.
## 완료 조건 (EARS)
- F-002-AC1: WHEN 인증된 HR이 유효한 이벤트를 승인한다 THE SYSTEM SHALL case와 outbox를 같은 트랜잭션에 저장한다.
- F-002-AC2: WHEN 연봉이나 면접 점수 필드가 포함된다 THE SYSTEM SHALL 422로 거부하고 원문 값을 응답하지 않는다.
