# F-010 · 승인·권한·실행 게이트
## 목적
payload와 actor/case/scope/expiry를 묶어 서버에서 권한을 확인한다.
## 완료 조건 (EARS)
- F-010-AC1: WHEN 승인 후 payload가 변경된다 THE SYSTEM SHALL 기존 승인을 무효화하고 실행을 거부한다.
- F-010-AC2: WHEN 승인되지 않은 외부 실행이 요청된다 THE SYSTEM SHALL 호출 전에 차단하고 감사 기록을 남긴다.
